運作原理

三件事，全自動發生

沒有公開的 Game Mode API，Gamely 靠系統 unified log 可靠偵測，再讀寫 Dock 偏好設定，全部不需要你動手。

1

偵測 Game Mode

監看 log stream，當 gamepolicyd 印出「Game mode is on」就知道全螢幕遊戲開始了。

2

暫停四個角落

先把你目前的 Hot Corner 設定存起來，把四角設成「無動作」，killall Dock 套用——遊戲全螢幕你看不見。

3

原封不動還原

遊戲一結束就把原值寫回。就算 Gamely 中途崩潰，下次啟動也會自動還原——保證不留爛攤子。

安裝

拖進「應用程式」就好

跟著四個步驟做，大約一分鐘。第三步會用到「終端機」，不用怕，複製貼上就好。

  1. 按這裡的「下載最新版」，從 GitHub 下載 Gamely 的 .zip 檔。
  2. 到「下載項目」資料夾雙擊 zip 解壓縮，把 Gamely 拖進「應用程式」資料夾。
  3. 打開「終端機」：按 ⌘ + 空白鍵 叫出 Spotlight，輸入「終端機」（英文系統輸入 Terminal），按 Return。
  4. 按下面黑色框右上角的「複製」，回到終端機按 ⌘ + V 貼上，再按 Return。Gamely 就會打開，之後從「應用程式」直接開就好。
xattr -dr com.apple.quarantine /Applications/Gamely.app && open /Applications/Gamely.app

常見問題

你可能想問

Gamely 是什麼？

一個 macOS 選單列小工具。Game Mode 一啟動，它就把四個 Hot Corners（熱點角落）暫時設成「無動作」，遊戲中滑鼠滑到角落不會再跳出 Mission Control、桌面或螢幕保護程式。遊戲結束後還原成你原本的設定，連修飾鍵都一樣。

跟自己去系統設定關掉熱點角落，差在哪？

手動關要記得關，也要記得開回來，四個角落原本各設了什麼還得自己記。Gamely 跟著 Game Mode 自動做這兩件事，你只管玩。

Steam、CrossOver 的遊戲沒反應？

macOS 只替全螢幕、而且被標成遊戲類別的 App 開啟 Game Mode。透過轉譯層跑的 Windows 遊戲通常不符合，Gamely 就不會動作。把這些遊戲加進「強制 App」，它們在前景時 Gamely 一樣會暫停 Hot Corners。

支援哪些 macOS 版本？

macOS 14 Sonoma 以上，Game Mode 是從 Sonoma 才有的。

為什麼第一次打開會被擋？

Gamely 是自簽的，沒有經過 Apple 公證，所以 macOS 會擋第一次開啟。照上面的安裝步驟跑一行指令、拿掉隔離標記就好；用 Homebrew 安裝會自動處理。

玩到一半 Gamely 當掉，熱點角落會不會回不來？

不會。原本的設定存在 Gamely 自己的偏好設定裡，下次啟動會發現 Game Mode 已經結束，自動還原。正常結束 Gamely 也會先還原再離開。

要錢嗎？

不用。Gamely 免費，以 CC BY-NC-SA 4.0 授權開源，原始碼在 GitHub。

寫在最後

我自己玩遊戲時，滑鼠滑到角落跳出 Mission Control 真的會氣到。系統有 Game Mode 卻不管 Hot Corners，那就自己補一個。

Gamely 很小、開源、免費。如果它也幫你擋掉了那一下掃興，那就值得了。
