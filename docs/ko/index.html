전체 화면 게임을 망치지 마세요

macOS 게임 모드가 켜지는 순간 Gamely가 네 개의 핫 코너를 모두 끄고, 게임이 끝나면 원래대로 되돌립니다. 메뉴 막대의 🎮 하나로 백그라운드에서 작동합니다.

작동 방식

하는 일은 세 가지, 모두 자동

게임 모드에는 공개 API가 없습니다. Gamely는 시스템 통합 로그로 정확히 감지하고 Dock 설정을 읽고 씁니다. 따로 할 일은 없습니다.

1

게임 모드 감지

log stream을 지켜보다가 gamepolicyd가 "Game mode is on"을 출력하면 전체 화면 게임이 시작된 것으로 판단합니다.

2

모서리 멈추기

현재 핫 코너 설정을 저장한 뒤 네 개 모두 '동작 없음'으로 바꾸고 killall Dock으로 적용합니다. 전체 화면 중이라 보이지 않습니다.

3

그대로 되돌리기

게임이 끝나면 원래 값을 다시 씁니다. 게임 중에 Gamely가 꺼져도 다음 실행 때 자동으로 되돌려 흐트러지지 않습니다.

기능

있는 줄도 잊을 만큼 작게

한 가지 일만 잘하고, 그 밖에는 귀찮게 하지 않습니다.

🎯

시스템 게임 모드를 따름

추측도 프로세스 검사도 하지 않습니다. macOS 공식 게임 모드 스위치만 따릅니다.

↩️

그대로 복원

보조 키까지 기억하므로 게임 후에도 모서리 설정이 똑같이 돌아옵니다.

🛟

꺼져도 안전

원래 설정은 Gamely 자체 환경설정에 저장됩니다. 예기치 않게 종료되면 다음 실행 때 감지해서 되돌립니다.

🚀

로그인 시 실행

SMAppService로 로그인 항목에 등록합니다. 한 번 설정하면 잊고 지내도 됩니다.

🍔

메뉴 막대 아이콘 하나뿐

Dock 아이콘도 알림도 없이 메뉴 막대에 게임패드 하나만 있습니다. 설정 창은 필요할 때 열면 됩니다.

🔀

언제든 끄기

메인 스위치를 끄면 Gamely는 아무것도 하지 않습니다. 핫 코너는 언제든 직접 되돌릴 수 있습니다.

🕹️

강제 앱

게임 모드를 켜지 않는 게임(Steam, CrossOver, Whisky)은 목록에 추가할 수 있습니다. 그 앱이 맨 앞에 있을 때도 모서리를 멈춥니다.

🌏

6개 언어

繁體中文, English, 日本語, 한국어, Español, Português. 시스템 언어를 따릅니다.

🔔

업데이트 확인

하루에 한 번 GitHub를 확인하고 새 버전이 나오면 메뉴에 업데이트 항목을 추가합니다. Homebrew로 설치했다면 brew upgrade만 하면 됩니다.

설치

'응용 프로그램'으로 드래그하면 끝

네 단계, 1분 정도면 됩니다. 3단계에서 터미널을 쓰지만 복사해서 붙여 넣기만 하면 되니 걱정하지 마세요.

  1. 최신 버전 다운로드를 클릭해 GitHub에서 .zip 파일을 받습니다.
  2. '다운로드' 폴더에서 zip을 두 번 클릭해 압축을 풀고 Gamely를 '응용 프로그램' 폴더로 드래그합니다.
  3. 터미널을 엽니다. ⌘ + Space로 Spotlight를 열고 터미널을 입력한 뒤 Return을 누릅니다.
  4. 아래 검은 상자 오른쪽 위의 복사를 클릭하고 터미널로 돌아가 ⌘ + V로 붙여 넣은 뒤 Return을 누릅니다. Gamely가 열리고, 그다음부터는 '응용 프로그램'에서 평소처럼 열면 됩니다.
xattr -dr com.apple.quarantine /Applications/Gamely.app && open /Applications/Gamely.app

이게 뭘 하는 건가요? Gamely는 Apple 공증을 받지 않은 무료 자체 서명 앱입니다. 앱 개발로 먹고사는 것이 아니라 제가 쓰기 좋고 보기 좋은 작은 것들을 만들 뿐이라, Apple의 연간 개발자 비용까지는 낼 수 없습니다… 그래서 macOS가 첫 실행을 막습니다. 이 명령은 다운로드할 때 붙은 '격리' 표시를 지우고 Gamely를 여는 것뿐, 다른 것은 바꾸지 않으며 한 번만 하면 됩니다.

Homebrew를 쓰나요? 한 줄로 설치되고 격리 표시도 함께 처리됩니다. 업데이트는 brew upgrade로.

brew install --cask rocavence/tap/gamely

궁금할 만한 것들

Gamely는 무엇인가요?

macOS 메뉴 막대 유틸리티입니다. 게임 모드가 켜지는 순간 네 개의 핫 코너를 '동작 없음'으로 바꿔서, 게임 중 마우스 실수로 Mission Control, 데스크탑, 화면 보호기가 뜨지 않게 합니다. 게임이 끝나면 보조 키까지 포함해 원래 설정으로 되돌립니다.

시스템 설정에서 핫 코너를 끄면 되지 않나요?

그러면 끄는 것도, 다시 켜는 것도, 네 모서리가 각각 무엇으로 설정되어 있었는지도 모두 기억해야 합니다. Gamely는 게임 모드에 맞춰 둘 다 자동으로 합니다.

Steam이나 CrossOver 게임에는 왜 반응하지 않나요?

macOS는 게임으로 분류된 전체 화면 앱에서만 게임 모드를 켭니다. 변환 계층으로 실행되는 Windows 게임은 대개 해당하지 않아서 Gamely가 따를 신호가 없습니다. 강제 앱에 추가하면 그 앱이 맨 앞에 있을 때 핫 코너를 멈춥니다.

어떤 macOS 버전을 지원하나요?

macOS 14 Sonoma 이상입니다. 게임 모드는 Sonoma에서 처음 나왔습니다.

첫 실행이 왜 막히나요?

Gamely는 자체 서명이고 Apple 공증을 받지 않아서 macOS가 첫 실행을 막습니다. 위 설치 단계의 한 줄 명령으로 격리 표시를 지우세요. Homebrew로 설치하면 알아서 처리됩니다.

게임 중에 Gamely가 꺼지면 핫 코너 설정이 사라지나요?

아니요. 원래 설정은 Gamely 자체 환경설정에 저장되어 있고, 다음 실행 때 게임 모드가 끝난 것을 확인하면 되돌립니다. Gamely를 정상적으로 종료할 때도 먼저 되돌린 뒤 종료합니다.

비용이 드나요?

아니요. Gamely는 CC BY-NC-SA 4.0으로 공개된 무료 오픈 소스이며, 코드는 GitHub에 있습니다.

마지막으로

게임 중에 마우스가 모서리에 닿아 Mission Control이 튀어나오면 정말 김이 샙니다. 시스템에 게임 모드는 있지만 핫 코너는 신경 쓰지 않아서, 빠진 조각을 직접 만들었습니다.

Gamely는 작고, 오픈 소스이며, 무료입니다. 여러분의 그 김새는 순간도 막아 준다면 만든 보람이 있습니다.
