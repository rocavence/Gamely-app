運作原理

三件事，全自動發生

沒有公開的 Game Mode API，Gamely 靠系統 unified log 可靠偵測，再讀寫 Dock 偏好設定，全部不需要你動手。

1

偵測 Game Mode

監看 log stream，當 gamepolicyd 印出「Game mode is on」就知道全螢幕遊戲開始了。

2

暫停四個角落

先把你目前的 Hot Corner 設定存起來，把四角設成「無動作」，killall Dock 套用——遊戲全螢幕你看不見。

3

原封不動還原

遊戲一結束就把原值寫回。就算 Gamely 中途崩潰，下次啟動也會自動還原——保證不留爛攤子。

功能

小到你會忘記它在

該做的事做好，其他什麼都不打擾。

🎯

跟隨系統 Game Mode

不靠猜測、不掃描程序，完全跟著 macOS 官方的 Game Mode 開關走。

↩️

精準還原

連修飾鍵設定都一起記住，遊戲結束後你的四角和原本一模一樣。

🛟

崩潰也安全

原值存在自己的偏好裡，意外結束後下次啟動會偵測並自動補還原。

🚀

開機自動啟動

用 SMAppService 註冊登入項目，裝一次之後就忘了它的存在。

🍔

只有選單列一個圖示

沒有 Dock 圖示、沒有視窗、不跳通知，背景安靜常駐。

🔀

隨時可關

總開關一關 Gamely 就完全不動作，也能手動立刻還原 Hot Corners。

安裝

拖進「應用程式」就好

下載解壓、拖進去。自簽 App 第一次打開用右鍵 → 打開，或跑下面這行清掉 quarantine。

# 清除 quarantine 後直接打開
xattr -dr com.apple.quarantine /Applications/Gamely.app
open /Applications/Gamely.app
