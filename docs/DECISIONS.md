# Gamely 決策紀錄

新的決策加在最上面。每筆寫明決定了什麼、為什麼，以及放棄了哪些做法。

## 2026-10-11 官網語言切換改用下拉選單

六種語言的按鈕排成一列，在手機寬度會超出畫面。改成下拉選單：按鈕顯示目前語言，展開列出全名。選項仍是一般連結，搜尋引擎能沿連結找到每個語言頁。

## 2026-10-11 官網六種語言各自一個靜態頁

`/`（繁體中文）、`/en/`、`/ja/`、`/ko/`、`/es/`、`/pt/` 都是完整的 HTML，hreflang 互相指向，`x-default` 指向英文。瀏覽器語言跟頁面不同時，只在頁首顯示提示連結，不自動轉址，避免搜尋引擎被導走。

放棄的做法：用 JavaScript 在同一頁換字。搜尋引擎與 LLM 只讀得到原稿語言。

## 2026-10-11 版本號：0.9.0 而非 1.0.0

ROADMAP 的 1.0 項目都已完成，但先以 0.9.0 發布，實際使用一段時間、沒有問題回報後再發 1.0.0。同一版本的修正以建置號區分（例如 0.5.2 b14），關於頁顯示「版本 b建置號」。

## 2026-10-11 授權改為 CC BY-NC-SA 4.0

與 Configgy、Findly、Flione、Wunder 一致：可自由使用、修改與分享，但不得商業使用，衍生作品需以相同授權釋出。

## 2026-10-11 App 圖示不改

0.5 原本計畫重做 App 圖示，決定維持原圖示，只換選單列圖示（Reicon `gamepad3` 加粗版，平時 outline、暫停中 filled）。

## 2026-10-11 選單列圖示暫停中不上重點色

以 outline 與 filled 區分狀態，不用顏色。選單列圖示要能在淺色與深色選單列都清楚，套用系統的範本圖示最穩定。

## 2026-10-11 通知預設關閉

暫停與還原時的通知預設不顯示，可在設定的「一般」開啟。遊戲開始時跳通知本身就是一種打擾。

## 2026-10-11 強制 App 在「最前面」才暫停

強制 App 清單裡的 App 在最前面時才暫停 Hot Corners，不是「執行中」就暫停。Steam 這類常駐背景的 App 加進清單後，熱角才不會一直被關掉。

## 2026-10-07 偵測 Game Mode 用統一記錄

macOS 沒有公開的 Game Mode API。`gamepolicyd`／`GamePolicyAgent` 切換時會在統一記錄印出 `Game mode is on/off`，Gamely 以 `log stream` 過濾這些訊息，啟動時用 `log show` 回讀最近 12 小時判斷初始狀態，兼做當機後的復原。

放棄的做法：掃描執行中的程式或全螢幕視窗猜測是不是遊戲，誤判太多。
